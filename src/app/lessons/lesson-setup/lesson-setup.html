Setup: a starter kit from a finished project

A new Angular 21 app, with the foundations of The Carbon Divide (../data-viz) copied in: the paper look, the lesson window, the flat map, the legend, the timeline. The home page is a title card for now; the first chart arrives in lesson 02.

1. The app

npx @angular/cli@21 new how-we-die --directory . --style scss --ssr false --skip-git --routing
  • Angular 21, standalone components, zoneless (the default since 21: the screen updates when a signal a template reads changes), no SSR. The same choices as The Carbon Divide, so its code drops in unchanged.
  • --skip-git: ng new would otherwise create a repository and an initial commit. Commits are yours to make.
  • Node 20 runs Angular 21; Angular 22 needs Node 22.
  • Libraries, at the versions The Carbon Divide uses: d3-array, d3-scale, d3-shape, d3-geo, topojson-client and gsap. Three.js is left out: this story has no globe.

2. What was copied, and why it was copied

The workspace rule: shared code is copied in, never linked out. A link out of the folder (../data-viz/src/…) breaks when this project is served or deployed on its own, and a copy can change here without touching the original.

  • The paper look: styles.scss (colour tokens, fonts) and styles/_paper.scss (the panel, field, segmented, tooltip-card and card-content mixins), plus the graph-paper backdrop (ui/backdrop, public/textures/graph-paper.svg).
  • The lesson window: ui/draggable, ui/floating-panel, ui/dock, lessons/lesson-window, lessons/lesson-page, the roadmap page. Lessons open in a movable, minimizable window over the product, on a named router outlet: /(lesson:lessons/setup).
  • For later lessons: charts/flat-map and charts/legend (lesson 07's map), ui/timeline (lessons 03 and 08), shared/motion-preference (reduced motion, for every animation), and the boundaries: data/boundaries.ts, data/country.ts (with income groups), data/format.ts, public/data/countries*.json and the script that built them.
  • app.config.ts keeps defaultQueryParamsHandling: 'merge': when this story's state goes in the URL (a country, a year), every navigation keeps it.

3. What was left behind

  • The globe, its shaders, extrusion, and Three.js; the CO₂ data and its pipeline; the explorer page, its state, the scatter plot, the compare tray, the story page. They are about carbon, or about a globe.
  • The story page (pages/story) and the line chart will be worth copying again when lessons 09 and 05 need them; copying now would carry code nobody uses yet.
  • The root component was rewritten small: a floating header (Home, Lessons), the page, the lesson window and the dock.
